## Findings

1. **From LangWatch board widgets are counted as `workbench`.** Every widget run on a curated board logs and counts `caller="workbench"` with no widget or template id. The board most new users see first is then mixed into the workbench numbers. Fix: send `telemetry` with `widgetId` (and the board template id) when `dashboardId` is absent.
2. **`dashboards.asked.langy` fires on app-made drafts**, not only on member asks: on every catalogue add, every "Edit code" open, after "Duplicate to edit" and after a template board is made. The ask count, and any "does Langy help" view built on it, will be inflated.
3. **The browser can name `caller` at the top level with no error.** It is dropped, so it is safe, but it is not the 400 the brief expects. Only `telemetry.caller` is refused.
4. **The "no project in scope" unregister of projectId was not observed.** PostHog persists super-properties, so an unmount-only `unregister` does not run on a full page load.
